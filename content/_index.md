## What is JSON Schema Conference?

The JSON Schema Conference brings together adopters, implementers, leaders and innovators
of the JSON Schema Ecosystem to further the education, adoption and evolution of the JSON Schema specification. In 2026, JSON Schema joins AsyncAPI, GraphQL, and OpenAPI at the API Standards Conference.
